# 原版卡牌蓝图库 · Codex

从编辑器顶部的「原版蓝图库」进入 `reference.html`。参考库包含当前解包输入中的全部 **2019** 份非 DIY `card_*` 蓝图：普通卡牌、战役、教程、乱斗、宣传卡、外观和副作用持有者均保留；没有效果函数的资源显示为仅默认数据。

## 浏览与使用

- 搜索卡名、效果、资源路径或函数名，按阵营和卡牌类型过滤；列表分页，蓝图内容按需读取。
- 切换 EventGraph 或函数，拖动画布平移、滚轮缩放；点击节点查看参数类型、折叠表达式和源指令地址。
- 默认完整展开：纯函数、布尔/算术运算、属性读取、数组、结构体和转换显示为节点与数据连线，高级引脚全部显示。需要概览时可在「逻辑显示」切换精简参考。
- 枚举参数可在节点内用下拉框选择。选择只修改当前参考副本，不覆盖共享原版数据。
- 「复制到工作区」创建独立资源；「导出参考蓝图」生成版本 2 的 `.kardsbp.json`。

## 手机操作

选卡列表按需打开，选定后返回画布。函数选择固定在顶部；卡牌信息、导出和显示模式位于「更多」。单指平移、双指缩放；底部可恢复可读比例、查看全图或定位具体节点。点击已连接引脚可沿线跳到生产/消费节点，点击节点标题打开详情底部面板。默认展示可读比例，只有点「全图」才缩放到整个图。

## 枚举

比较节点保留 `EFactionEnum`、`ESideEnum` 等类型与命名值，不以 `EqualEqual_ByteByte` 或数字替代枚举。烘焙时降低成比较与跳转链的内置枚举执行分支，例如 `WhichChooseOne`，恢复成函数上的命名执行出口，未连接分支也保留枚举出口。

编辑器新增「Select (Enum)」「Equal (Enum)」「Not Equal (Enum)」。选择与比较随连接推断枚举类型，不同枚举不能混接；Select 的值类型随数据连接推断。导入和导出保留自定义枚举声明，包括具有自定义数值和显示名的 `CardMoveReason`。

## 还原范围与证据

本库从 FModel 烘焙 Kismet 数据还原逻辑参考图，不生成 Unreal `.uasset`，不执行游戏逻辑。烘焙已剥离原编辑器布局，因此坐标是自动生成的，不声称还原原始坐标、注释框或宏的原始外观。

保留 **5585** 个函数和 **80736** 条顶层源指令，包含操作数的指令计数也逐种与源文件核对。`reference-data/inventory.json` 记录源相对路径、SHA-256、原始及标准化指令统计。函数、参数、局部变量、默认值和指令地址可在界面中展开核对。

现有 C++ / UE 声明用于恢复参数名称、方向和类型。可用 SDK 缺少的四个调用，使用调用点反射类型并明确标为调用点证据；没有名称证据的输入显示为 `Arg0`、`Arg1`，不伪造参数名。多处写入、无法唯一确定生产节点的数据变量保留为带原始变量名和类型的读取节点，不猜测生产连线。

## 更新数据

拥有对应的解包数据和 UE 头文件后运行：

```sh
python tools/generate-reference-library.py --exports /path/to/Exports/kards/Content --engine-runtime /path/to/UE_5.6/Engine/Source/Runtime
npm test
npm run lint
npm run test:browser
```

生成器排除 DIY 目录，遇到未覆盖指令或指令计数不一致会失败。提交数据按卡牌拆分；站点不依赖绝对磁盘路径。
